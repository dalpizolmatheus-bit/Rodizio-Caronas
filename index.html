Falta configurar a planilha 🚗

Este arquivo ainda não está ligado a nenhuma planilha do Google. Siga o guia de configuração que veio junto com este arquivo:

  1. Crie a planilha Google e cole o script (Apps Script) do guia.
  2. Publique o script como "Web app" (execução: você / acesso: qualquer pessoa).
  3. Copie a URL gerada e cole na constante API_URL, perto do topo do <script> deste arquivo.
  4. Salve o arquivo e reabra — a partir daí ele já pode ser enviado para os colegas normalmente.

Colegas

O campo "carro" é opcional. Deixe em branco se a pessoa tem carro próprio. Para quem divide o mesmo carro, digite o mesmo texto no campo de ambos (ex.: "Gol prata") — a meta daquele carro passa a somar a fatia de cada pessoa do grupo automaticamente.
